# Telegram 频道自动加入虚拟存储

0.2.40 新增普通 Telegram 账号订阅。读取账号已经加入的公开／私有频道，提取115分享链接和同条消息中的提取码，进入原有虚拟分享导入队列。识别与命名由 MoviePilot 完成，生成 STRM 后显示在虚拟存储列表。导入不转存视频、不创建115目录、不删除文件；播放时沿用原来的临时转存和到期清理流程。

0.2.41 起，Telegram 在配置页和详情页中都是独立的同级标签，内部分为“账号连接 / 频道订阅 / 导入记录”。切换板块保留未保存输入，Telegram 隐藏时暂停页面状态刷新；后台订阅仍按已保存设置运行。

## 配置

1. 更新插件并重启 MoviePilot，确保新依赖 Telethon 1.45.0 和 python-socks 已安装；启用115工具箱，配置115 Cookie、STRM目录和播放地址。
2. 在 Telegram 使用需要订阅的普通账号加入目标频道。在 [my.telegram.org](https://my.telegram.org) 的 API development tools 获取此应用的 API ID 与 API Hash。
3. 打开插件配置或详情页的“Telegram”标签。在“账号连接”填写 API ID、API Hash；在“频道订阅”填写频道列表，每行一个。公开频道支持 `@channel_name` 或 `https://t.me/channel_name`，私有频道使用 `-100` 开头的频道ID；不接受邀请链接、单条消息地址或聊天群。默认不自动加入频道。
4. 按需要填写 Telegram 代理，如 `socks5://host:1080`、`http://host:8080`，或包含用户名与密码的同格式地址。地址必须能从 MoviePilot 容器访问；容器内的 `127.0.0.1` 指向容器自身。代理仅作用于 Telegram。
5. 在“账号连接”保存连接设置。输入包含国家区号的手机号，发送验证码，在页面内填写 Telegram／短信验证码并登录。如果提示需要二步验证，再填写账号密码后登录。
6. 在“频道订阅”勾选启用订阅并保存。默认每60秒检查，范围30–3600秒。成功读取频道后，首次默认只记录当前最新消息边界，随后处理新消息；如需历史资源，在首次读取该频道前把“首次回看消息数”设为1–500。已有进度的频道继续从保存的位置读取，修改回看数量不会重置进度。

Telegram 设置单独保存，原有配置页的保存不会覆盖它。留空 API Hash 或代理会保留旧值，清除代理需显式勾选选项。修改API凭证或代理会断开当前连接，进行中的验证码登录需要重新开始。使用账号会话重新连接不需要每次输入验证码。

首次播放前仍需在“存储设置”选择115专用临时转存目录。Telegram 订阅和虚拟资源导入不需要该目录。

## 消息、队列及重试

- 支持消息正文中的直接115链接、隐藏文字链接和按钮URL。只接受现有115分享格式，不访问中转网站；提取码可以位于链接的 `password` 参数或同条消息的“提取码／密码／访问码”等标签后。
- 同条消息有多个分享时按各链接后方的文字分别找提取码。多个提取码无法唯一对应时记录“提取码有歧义”，请到原存储页手动导入；不会猜测密码。提取码位于另一条消息、消息后续编辑、新增按钮和中转网页暂不自动追踪。
- 分享码与提取码相同的链接跨频道、跨重启只登记一次。相同分享后续新增视频不会因重复发布而自动重新扫描；如需更新，使用原存储页手动重新导入。
- 本地最多保存1000项尚未完成的订阅导入，再复用原有最多100项等待的分享队列。队列满时保留频道进度，后续继续读取，不将未接收的消息标记为已处理。每次每频道最多继续读取100条，逐批赶上新消息。
- 最近50项显示频道ID、消息ID、固定状态和成功／失败数。识别、输出冲突或分享失效等失败不无限重试，可核实后点击“重试”；修正提取码或手动选择不同链接请使用原存储页导入。
- 尚未入队的订阅链接跨重启保留；重启时已经运行或排队的项显示“已中断”，由用户手动重试。复用稳定资源ID及播放标识，已有临时副本及远程未知写检查点继续使用原有保护。原来手动添加分享的内存队列行为不变。
- 自动读取仅在启用订阅时进行。关闭后不再读取或提交新的订阅导入，已经交给存储队列的任务继续完成。Telegram 返回限流等待时暂停自动检查和登录请求，等待后再尝试；不会自动登录、退群或向频道／其他账号发消息。

## 凭证与诊断

API Hash、代理和账号会话保存在插件数据目录的私有文件，POSIX权限为0600。验证码、手机号码和二步验证密码不写入配置、数据库、日志或状态响应；登录成功后清除内存中的验证码登录上下文。API Hash、完整代理、账号会话、分享链接、提取码和播放标识不出现在订阅任务摘要中。

账号会话与登录凭证同等敏感；不要复制到仓库或聊天。停止使用时先关闭订阅；可在 Telegram 官方客户端的“设备”页撤销此登录会话。此版本不提供页面远程退出会话按钮。

`CHANNEL_NOT_JOINED` 表示当前账号的已加入频道中未找到该引用，检查账号、频道用户名或私有频道ID；`CHANNEL_UNAVAILABLE` 表示已找到但读取失败。`DEPENDENCY_MISSING` 请重新安装依赖并重启宿主。连接错误统一显示脱敏提示，检查 Telegram 网络、代理和 API 凭证。`RATE_LIMITED` 需要遵守上游等待，立即检查不会绕过限制。

## 构建与验证边界

当前发布仓库缺少原有 Vue 源码，保留已发布联邦模块作为基线，在 `frontend/telegram/` 添加原生 ES 模块扩展，包装原有 Config／Page 并使用宿主共享 Vue。`python tools/build_telegram_ui.py` 同步资源和指纹；`python tools/build_moviepilot.py` 检查版本与资源指纹并生成两个ZIP。原基线的源码指纹保留在 `baseline_sources`，不宣称本次重建了缺失的旧Vue源码。

离线测试覆盖解析、去重、分页、背压、恢复、登录、限流、持久结果和虚拟导入；浏览器测试使用模拟API验证保存、验证码／二步验证、失败重试、联邦加载及390像素布局。真实 MoviePilot v2.15.6 验证临时配置、插件启停及管理员接口约定。未使用真实 Telegram 账号或115分享，未测试真实转存、播放或删除；真实频道格式、网络和媒体识别结果需配置后验收。

接口依据：[Telethon 登录](https://docs.telethon.dev/en/stable/basic/signing-in.html)、[客户端与分页方法](https://docs.telethon.dev/en/stable/modules/client.html)、[账号会话](https://docs.telethon.dev/en/stable/concepts/sessions.html)。
