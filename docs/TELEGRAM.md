# Telegram 频道自动加入虚拟存储

0.2.42 提供两种接入方式。默认“公开网页”模式无需申请 API ID/API Hash、无需登录账号或加入频道；原“Telegram账号”模式保留，用于已经取得API凭证并登录的账号读取已加入频道。旧版本升级保留原账号设置，不自动更换模式。两种模式都提取115分享链接与同条消息中的提取码，使用原分享导入、MoviePilot虚拟整理和STRM流程，导入时不转存、不创建115目录、不删除文件；播放时沿用原临时副本链路。

配置页和详情页均有独立“Telegram”标签，内部为“连接设置 / 频道订阅 / 导入记录”。切换保留未保存输入，离开Telegram时暂停页面状态刷新，后台订阅按已保存设置继续运行。

## 公开网页模式：免API配置

1. 更新插件并重启 MoviePilot。启用115工具箱，配置115 Cookie、STRM目录和播放地址；新依赖为 `httpx[socks]>=0.28,<1`。
2. 打开“Telegram → 连接设置”，选择“公开网页（免 API、免登录）”。如果MoviePilot无法直连Telegram，填写HTTP或SOCKS5代理，保存连接设置。此模式不会显示API凭证、手机号、验证码或二步验证表单。
3. 在“频道订阅”填写公开频道，每行一个，最多30个。支持 `@channel_name`、`https://t.me/channel_name` 和 `https://t.me/s/channel_name`。不接受私有频道数字ID、邀请链接或单条消息地址。
4. 按需要设置首次回看数量，默认0仅记录首次成功读取的最新消息边界，随后读取新消息；1–500回看最近相应条数。已有进度的频道继续读取新消息，更改数量不重置进度。
5. 勾选“启用频道订阅”并保存。默认每60秒检查，范围30–3600秒。可在“导入记录”查看结果或重试失败项。

公开网页模式只访问固定 `https://t.me/s/频道名`，使用数值 `after` 从游标逐页向前读取，不因积压跳过消息。首次回看使用 `before` 向前回溯，最多读取30页；请求较慢、回看量过多或超过分页上限时可降低回看数量。只有完整、身份一致且可识别的频道页面才提交消息；不存在、受限制、被重定向、截断或无法识别的页面不会推进已有游标。只处理网页公开的正文、隐藏文字链接和URL按钮；账号可见但网页未公开的内容无法读取。

网页结构和公开范围由Telegram决定。公开频道若无法网页预览，此模式会提示不可用，不能读取私有、登录后或受限制的消息。网页模式与账号模式分别保存读取进度，共享分享去重；切换方式后不会因同一链接重复登记资源。

## Telegram账号模式

需要该模式时，在“连接设置”选择“Telegram账号（需要 API）”。先通过 [my.telegram.org](https://my.telegram.org) 获取 API ID/API Hash并保存，再输入含国家区号的手机号发送验证码、在插件页面登录；提示二步验证时填写账号密码。此模式读取账号已经加入的频道，不自动加入、退群或发送消息。公开频道支持频道名，私有频道使用 `-100` 开头的频道ID。

代理支持 `socks5://host:1080`、`http://host:8080` 及同格式的用户名密码。地址须能从MoviePilot容器访问；容器中的127.0.0.1指向容器自身。代理只作用于Telegram。留空API Hash或代理会保留旧值，清除代理需显式勾选；改变模式、凭证或代理会断开当前连接，进行中的验证码登录需重新开始。账号会话文件保留，可在原账号模式复用，不需要每次登录。

Telegram设置单独保存，原115配置页的保存不会覆盖它。首次播放仍须在“存储设置”选择115专用临时目录，虚拟资源导入本身不需要临时目录。

## 消息、队列及重试

- 支持消息正文中的直接115链接、隐藏文字链接和按钮URL。只接受现有115分享格式，不访问中转网站；提取码可以位于链接的 `password` 参数或同条消息的“提取码／密码／访问码”等标签后。
- 同条消息有多个分享时按各链接后方的文字分别找提取码。多个提取码无法唯一对应时记录“提取码有歧义”，请到原存储页手动导入；不会猜测密码。提取码位于另一条消息、消息后续编辑、新增按钮和中转网页暂不自动追踪。
- 分享码与提取码相同的链接跨频道、跨重启只登记一次。相同分享后续新增视频不会因重复发布而自动重新扫描；如需更新，使用原存储页手动重新导入。
- 本地最多保存1000项尚未完成的订阅导入，再复用原有最多100项等待的分享队列。队列满时保留频道进度，后续继续读取，不将未接收的消息标记为已处理。账号模式每频道每轮最多继续100条；网页模式每频道每轮继续一个公开网页（实测通常20条），逐批赶上新消息。
- 最近50项显示频道名或频道ID、消息ID、固定状态和成功／失败数。识别、输出冲突或分享失效等失败不无限重试，可核实后点击“重试”；修正提取码或手动选择不同链接请使用原存储页导入。
- 尚未入队的订阅链接跨重启保留；重启时已经运行或排队的项显示“已中断”，由用户手动重试。复用稳定资源ID及播放标识，已有临时副本及远程未知写检查点继续使用原有保护。原来手动添加分享的内存队列行为不变。
- 自动读取仅在启用订阅时进行。关闭后不再读取或提交新的订阅导入，已经交给存储队列的任务继续完成。Telegram 返回限流等待时暂停自动检查和登录请求，等待后再尝试；不会自动登录、退群或向频道／其他账号发消息。

## 凭证与诊断

API Hash、代理和账号会话保存在插件数据目录的私有文件，POSIX权限为0600。验证码、手机号码和二步验证密码不写入配置、数据库、日志或状态响应；登录成功后清除内存中的验证码登录上下文。API Hash、完整代理、账号会话、分享链接、提取码和播放标识不出现在订阅任务摘要中。

账号会话与登录凭证同等敏感；不要复制到仓库或聊天。停止使用时先关闭订阅；可在 Telegram 官方客户端的“设备”页撤销此登录会话。此版本不提供页面远程退出会话按钮。

`WEB_CHANNEL_UNAVAILABLE` 表示公开网页不可读取，检查频道名及其网页公开范围；`WEB_REQUEST_FAILED` 检查网络和代理；`WEB_PAGE_INVALID` 表示网页结构、身份或完整性检查失败，进度保留；`WEB_HISTORY_LIMIT` 请降低首次回看数量；`WEB_PAGE_TOO_LARGE` 表示单页解压内容超过2MiB。HTTP 429遵守Retry-After等待（无有效值时默认300秒），立即检查不会绕过等待。

`CHANNEL_NOT_JOINED` 表示当前账号的已加入频道中未找到该引用，检查账号、频道用户名或私有频道ID；`CHANNEL_UNAVAILABLE` 表示已找到但读取失败。`DEPENDENCY_MISSING` 请重新安装依赖并重启宿主。连接错误统一显示脱敏提示，检查 Telegram 网络、代理和 API 凭证。`RATE_LIMITED` 需要遵守上游等待，立即检查不会绕过限制。

## 构建与验证边界

当前发布仓库缺少原有 Vue 源码，保留已发布联邦模块作为基线，在 `frontend/telegram/` 添加原生 ES 模块扩展，包装原有 Config／Page 并使用宿主共享 Vue。`python tools/build_telegram_ui.py` 同步资源和指纹；`python tools/build_moviepilot.py` 检查版本与资源指纹并生成两个ZIP。原基线的源码指纹保留在 `baseline_sources`，不宣称本次重建了缺失的旧Vue源码。

离线测试覆盖解析、去重、分页、背压、恢复、登录、限流、持久结果和虚拟导入；浏览器测试使用模拟API验证保存、验证码／二步验证、失败重试、联邦加载及390像素布局。真实 MoviePilot v2.15.6 验证临时配置、插件启停及管理员接口约定。新增公开网页模式已只读检查Telegram官方 `@telegram` 的最新页与after分页，均解析出20条消息。未使用真实Telegram账号或真实115分享，未测试真实转存、播放或删除；目标资源频道格式、网络和媒体识别结果需配置后验收。

接口依据：[Telethon 登录](https://docs.telethon.dev/en/stable/basic/signing-in.html)、[客户端与分页方法](https://docs.telethon.dev/en/stable/modules/client.html)、[账号会话](https://docs.telethon.dev/en/stable/concepts/sessions.html)。

公开网页依据：[Telegram官方频道网页](https://t.me/s/telegram)、[公开消息网页嵌入说明](https://core.telegram.org/widgets/post)。网页分页来自只读实测，不能当作稳定的官方API协议。
