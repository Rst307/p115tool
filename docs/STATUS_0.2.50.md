## 0.2.50 原生授权播放已存在的虚拟副本

修复虚拟资源已有临时副本时，原生授权播放仍被 `COOKIE_MODE_REQUIRED` 拒绝的问题。插件只读核实记录的目录、唯一文件、大小和 SHA1，再通过原生接口获取 302 链接，原 STRM 地址继续使用。可以复用晚到的已核实副本，当前版没有副本时最多检查一个历史版本。成功后只更新本地播放租约，已有转存及删除检查点保留。

没有可用副本时，播放日志记录 `COOKIE_TRANSFER_REQUIRED`。切回 Cookie 模式播放一次完成转存，之后可以切回原生授权。原生授权下的播放分支不会提交转存或删除，也不会自动切换凭据。

离线复现原有日志及 HTTP 503，修复后同一播放地址返回 302。原生授权、原有播放恢复、画质选源和安装包共 53 项相关检查通过。最终联邦页面通过无头 Edge 验证，两个安装包完成版本、字节及归档验证。未使用真实账号或网盘文件。
