## 0.2.49 MoviePilot 原生 115 授权

在 MoviePilot 存储设置登录 115 后，打开工具箱「通用连接」，开启「使用 MoviePilot 原生 115 授权」并保存。原生模式支持目录浏览、实际库存扫描、生成 STRM 以及实际文件的 302 播放。已有配置默认继续使用 Cookie 模式。

所有请求统一经 P115ClientManager。插件按次读取宿主管理的访问令牌，刷新由宿主处理。原生模式仅调用开放目录、详情和取链接口，按文件 ID 核实取链结果，保留播放器 User-Agent 和现有 CDN 校验。授权拒绝时停止本次请求，不切换到已保存的 Cookie，也不将令牌放入日志、响应或插件配置。

原生模式暂停分享导入、虚拟播放、临时副本清理、回收站操作和 Telegram 导入，保留已有配置、任务检查点及订阅游标。切回 Cookie 模式可继续使用这些功能。MoviePilot 移动整理仍由宿主处理。

后端离线回归 387 项、前端测试 16 项全部通过。新增 5 项使用真实 SDK 的请求组装和模拟 HTTP 响应，覆盖宿主令牌更新、目录识别、STRM 和 302 路由、无授权及失效时不回退、链接身份验证和旧回收站检查点保留。最终联邦页面在无头 Edge 验证了开关、保存配置、存储操作和 390 像素布局，两个安装包核验版本和文件完整性。未接入正式 MoviePilot 或真实 115 账号，未操作真实媒体。
