# 0.1.4：目录选择、STRM分类和运行日志

## 使用

1. 先保存插件115账号配置。进入原生插件配置的STRM组，点击“选择115文件夹”，逐层进入目录后点击“选择当前文件夹”，支持多个扫描目录。整理和缓存目标也使用目录选择；禁止把个人盘根目录作为这些写入目标。
2. 开启“STRM按类型分类”和／或“STRM按类别分类”，保存配置，再扫描或对已有媒体执行“生成STRM”。分类开关默认关闭，旧目录配置仍兼容。
3. 在MoviePilot宿主日志搜索“115 工具箱”。可看到配置生效、停止服务、任务ID及类型、运行／完成／失败、扫描目录进度和计数、STRM写入、分享和恢复操作状态。插件任务与媒体详情也保留操作记录。

## 分类范围

读取宿主 `MediaChain.recognize_by_path(..., obtain_images=False)` 返回的 `media_info.type` 和 `media_info.category`，遵循宿主已配置的类别规则，不在插件里复制一套固定国家／类型分类表。

例如源虚拟路径 `/emby_raw/影片.mkv`，开启两个开关后输出：

`<STRM目录>/电影/华语电影/emby_raw/影片.mkv.strm`

分类只改变本地STRM位置；源目录层级与原文件名保留。智能改名、115端移动、刮削属于已有自动整理功能，独立配置。重新生成时刷新宿主分类，验证STRM时仅读持久化分类，不触发识别。识别不可用时保留此前已知分类；首次无结果使用“未识别／未分类”，后续生成可以恢复识别。类型可使用已存媒体类型兜底。分类字符串做单目录名净化。

迁移仍先原子写入新STRM，然后只清理同一输出根目录内内容与本插件播放URL完全相同的旧STRM。用户编辑过的STRM受到保护；播放token保持稳定，不删除115源媒体。

## 账号和宿主边界

文件夹选择器使用插件配置的115账号，通过统一的 `P115ClientManager` 查询个人盘，后台保存CID，用户无需手工输入。尚未复用MoviePilot官方115存储的OAuth登录；官方存储与本插件账号需要指向同一个115账号才能看到相同目录。官方OAuth授权不能直接当作本插件SDK Cookie使用。插件未启动时也可使用已保存的Cookie浏览，临时管理器查询后关闭。

原生文件夹接口沿用MoviePilot激活管理员鉴权和请求体校验，仅返回目录名／CID与分页总数，不返回SDK原始响应、文件直链或凭据。宿主日志只输出明确的操作状态、数字计数和内部ID，不输出任务detail、异常原文、Cookie、分享密码、播放token或直链。
