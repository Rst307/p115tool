## 0.1.6 整理后统一扫描

先在MoviePilot正常整理，插件每天指定时间扫描整理后的115目录。默认03:00，默认时区北京时间。扫描只建立虚拟索引；虚拟分享和STRM各自为独立任务，可独立自动执行或点击“开始创建虚拟分享”“开始生成STRM”。手动扫描完成后再启动所需输出任务。分享阶段保留源且不生成STRM，未生成STRM不能绕过历史删除门禁。整理事件只记录分类元数据，扫描不会再次委托整理。请将插件扫描目录设置为整理后媒体库，详见[使用说明](docs/POST_ORGANIZE_SCAN.md)。

## 0.1.10 STRM生成失败提示

批量生成需要最近一次完整成功扫描。任务详情现在说明缺少快照或目录配置变化；逐媒体日志区分写权限、文件冲突及其他本地生成失败。先确认扫描成功再生成，详见[排查说明](docs/STRM_FAILURES.md)。仅有旧版NEEDS_ATTENTION日志时仍不能确认实机原因。
