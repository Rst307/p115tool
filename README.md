# 115 工具箱 · MoviePilot 原生插件

当前版本 **0.2.18**。提供实际存储和虚拟存储两种方式，支持115分享导入、临时转存及到期清理、库内资源分享后虚拟化、分类STRM、302播放和MoviePilot移动整理。

实际存储的视频长期保留在自己网盘。虚拟存储保留分享映射、索引和STRM，视频用临时副本播放；到期清理后，下次播放需要时重新转存。临时副本是虚拟存储的内部状态。

在MoviePilot插件仓库添加 https://github.com/Rst307/p115tool ，刷新插件市场并更新“115 工具箱”。支持目标为MoviePilot v2.15.6、Python3.12+。

1. 保存115 Cookie并启用插件。
2. 选择一个或多个115源文件夹；也可输入目录ID和该目录的完整网盘路径。
3. 设置STRM输出目录，例如 `/opt/emby/strm`。这是MoviePilot容器内路径，需要挂载并赋予写权限，Emby也需挂载该目录。
4. 设置Emby可以访问的MoviePilot地址，例如 `http://192.168.1.10:3000`。
5. 详情页点击“生成STRM”。可另行开启每天自动生成，时间为北京时间。

网盘已有 `/电影/外语电影/影片/影片.mkv` 分类时，输出 `/opt/emby/strm/电影/外语电影/影片/影片.mkv.strm`。选中电影或类别子目录也保留该分类。未分类资源使用MoviePilot识别类型和类别；无法识别时放入 `未识别/未分类/`，保留源目录内的子目录结构。

STRM仅保存插件稳定播放地址，播放时透传播放器User-Agent取得115直链并返回302，不代理视频。生成按钮直接扫描并输出，不需要先执行单独扫描，也不依赖旧整理或分享检查点。

MoviePilot负责影视整理。详情页可勾选独立配置的MoviePilot待整理文件夹并点击“一键整理”，交给MoviePilot原生TransferChain递归处理，固定move移动整理，成功后文件从待整理目录移至媒体库；媒体识别、命名、分类、目标目录和附加文件由宿主规则决定。需要先在MoviePilot登录同一115账号、配置媒体库目录；目录ID与完整路径不一致则拒绝提交。整理进度和结果在MoviePilot整理任务／历史查看，插件不记录整理事件或建立整理数据库。源目录重叠时只提交最上层；未知结果停止剩余提交且不自动重试。STRM生成源目录单独设置为整理后的媒体库，例如 /emby，再独立生成STRM。

在“存储设置”选择专用115临时目录（非根目录），设置副本保留天数（默认7天），保存后到“存储”板块导入分享。插件生成STRM并初次转存；每小时15分检查清理，到期且播放保护已结束才删除副本。每次播放延后至少24小时清理；分享失效或副本身份无法核实时保留文件。不会清空回收站，空临时子目录保留复用。

实际存储列表直接递归扫描“STRM生成源文件夹”，请将其设为整理后的媒体库。打开存储页自动扫描，也可点击“重新扫描媒体库”；无需先生成STRM，临时副本目录不计入。只有全部目录扫描成功后更新列表，已删除或移出目录的资源从列表隐藏；扫描失败保留上次完整结果并显示失败提示。搜索、分页及刷新状态读取扫描快照，上次扫描时间显示在页面。修改源目录后旧范围的实际列表隐藏，等待新扫描。扫描不删除网盘文件或现有STRM，历史播放映射及检查点保留。

在存储列表选择实际资源点击“转为虚拟存储”，或点击“全部实际存储转为虚拟”，并勾选删除源视频授权。全部转换先完整重扫所有配置的媒体库，覆盖全部分页，不受搜索筛选限制；扫描失败不开始转换。插件确保STRM可用，直接创建长期分享并验证文件身份和分享播放，再删除源视频，保留原STRM和播放地址。转换不创建临时目录或转存副本，无需配置临时目录。分享验证失败保留源；未知写结果或删源后分享失效停止本批后续资源。

虚拟资源播放时才按需转存，播放前须配置临时目录。手动删除转存视频后，下次播放请求确认缺失会立即重新转存；插件临时子目录一并删除时先重建子目录。文件在存在检查后、获取直链前被删除，也在同一次请求内核实并恢复一次。身份变化、未知写结果、根目录丢失及普通网络错误不触发盲目重转存。

未知写结果不会自动重试。选择资源点“只读核实结果”，仅在明确查到已完成结果后更新本地状态；无法确定的保留检查点。分享创建超时可在网盘找到已生成分享，再用“接入已创建分享”核实接入，后续虚拟化复用它。未知删除仍查到文件存在时不会重发删除，需人工核实网盘后继续。

Cookie及分享提取码不写日志、任务或错误响应；分享信息保存在运行数据库，列表不返回私密播放地址。请备份插件数据目录和STRM，虚拟资源依赖数据库映射。旧0.1.x数据库和任务不恢复；实际源保留token迁移。手工修改的STRM保留，已确认归属的旧路径和播放地址按检查点更新。

升级后重新加载插件并强制刷新浏览器。新功能已通过离线测试及原生安装包检查，真实115、MoviePilot页面与Emby播放仍需部署验证。详情见 [当前状态](docs/STATUS.md)。

0.2.4按每个文件的115列表完整路径输出分类，并展示前10条网盘／STRM路径示例。完整生成成功后，旧位置内容与本轮已生成文件的稳定播放地址完全相同、文件名相同且位于输出根内的STRM会先记录本地迁移意图再移除；空旧目录随之移除。已编辑文件、其他文件、根外路径与符号链接保留，未知迁移不重试。仅调整本地STRM，不操作网盘源。

0.2.5配置页分为“STRM生成源文件夹”（例如115的 `/emby`）和“MoviePilot待整理文件夹”（例如115的 `/下载/待整理`）。本地STRM输出仍设为 `/opt/emby/strm`。一键整理只处理待整理列表，STRM生成只扫描生成源列表，MoviePilot整理目标依其媒体库规则。升级保留STRM源配置，待整理列表为空，需要单独选择并保存。

0.2.6修复修改服务地址后旧STRM内容冲突、仍指向旧地址的问题。MoviePilot和Emby在不同Docker容器时，播放地址应使用Emby能访问的MoviePilot局域网地址或域名，例如 `http://192.168.0.2:3000`，不带 `/#/plugins`，不要填Emby地址。保存后重新生成即可更新已确认归属的输出，token和目录不变。旧版默认 `127.0.0.1`／`localhost` 的8000／3000端口，仅在数据库记录路径、源身份及精确token一致时兼容更新；其他未记录的不同内容仍保留。新输出记录内容指纹，后续地址修改校验指纹；替换前提交检查点，原子替换，未知结果不重试，不记录播放URL或token到任务日志。

## 0.2.7 界面优化

原生配置页按连接与播放、STRM媒体库、待整理目录、自动生成分组；手动填写按需展开，目录为空、重复添加和读取失败给出提示。详情页优先显示生成状态与文件数量，整理操作单独展示，生成路径可展开核对。支持宿主亮色／深色主题与手机布局。升级后若仍显示旧界面，请强制刷新页面。

## 0.2.8 整理后自动生成STRM

在配置页“STRM”板块中开启“整理完成后自动生成STRM”并保存，默认关闭。MoviePilot成功整理到115后，连续事件合并等待10秒，扫描已配置的STRM生成源；需将整理目标媒体库配置为生成源。扫描期间的新事件会补扫，关闭或重载取消待执行任务；手动生成和每日生成仍可独立使用。此功能仅响应新的成功事件，不记录整理事件，不自动整理或修改网盘源。

## 0.2.9 定时整理与功能分板块

详情页分为整理、STRM；设置页分为整理、STRM、通用连接。整理板块仅显示待整理目录和每日整理时间；STRM板块显示生成源、输出目录、播放地址与自动生成；Cookie、启用开关和请求超时位于通用连接。切换设置板块保留未保存修改，保存统一提交完整配置。

在整理设置开启“每天自动整理”，设置北京时间并保存。默认关闭，处理全部已配置待整理目录，手动勾选仅影响当次手动提交。仍由MoviePilot按copy处理，不存整理事件；重叠目录只提交祖先，空目录列表不注册整理任务，STRM运行中跳过当次整理。宿主提交结果未知会暂停本服务后续提交并保存关闭定时整理；核实MoviePilot任务后重新保存配置，再决定是否开启。
