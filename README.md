# 115 工具箱 · MoviePilot 原生插件

当前版本 **0.2.3**。按用户2026-09-30的新要求，提供指定115个人网盘文件夹递归生成分类STRM、实时302直链播放，以及将选定文件夹委托MoviePilot的一键整理入口。

在MoviePilot插件仓库添加 https://github.com/Rst307/p115tool ，刷新插件市场并更新“115 工具箱”。支持目标为MoviePilot v2.15.6、Python3.12+。

1. 保存115 Cookie并启用插件。
2. 选择一个或多个115源文件夹；也可输入目录ID和该目录的完整网盘路径。
3. 设置STRM输出目录，例如 `/opt/emby/strm`。这是MoviePilot容器内路径，需要挂载并赋予写权限，Emby也需挂载该目录。
4. 设置Emby可以访问的MoviePilot地址，例如 `http://192.168.1.10:3000`。
5. 详情页点击“生成STRM”。可另行开启每天自动生成，时间为北京时间。

网盘已有 `/电影/外语电影/影片/影片.mkv` 分类时，输出 `/opt/emby/strm/电影/外语电影/影片/影片.mkv.strm`。选中电影或类别子目录也保留该分类。未分类资源使用MoviePilot识别类型和类别；无法识别时放入 `未识别/未分类/`，保留源目录内的子目录结构。

STRM仅保存插件稳定播放地址，播放时透传播放器User-Agent取得115直链并返回302，不代理视频。生成按钮直接扫描并输出，不需要先执行单独扫描，也不依赖旧整理或分享检查点。

MoviePilot负责影视整理。详情页可勾选已配置的源文件夹并点击“一键整理”，交给MoviePilot原生TransferChain递归处理，默认copy复制保留源；媒体识别、命名、分类、目标目录和附加文件由宿主规则决定。需要先在MoviePilot登录同一115账号、配置媒体库目录；目录ID与完整路径不一致则拒绝提交。整理进度和结果在MoviePilot整理任务／历史查看，插件不记录整理事件或建立整理数据库。源目录重叠时只提交最上层；未知结果停止剩余提交且不自动重试。整理完成后，将配置源目录指向整理目标，再单独生成STRM。

插件没有整理事件监听、虚拟分享、缓存转存、源删除、回收站或健康修复功能。旧库普通且保留源的播放地址会迁移；原虚拟分享／缓存资源不再支持，需选择实际存在的115源目录重新生成。旧数据库保留作为历史，旧后台任务不会执行。已有STRM不会被删除；内容不一致的文件不会被覆盖。

升级后重新加载插件并强制刷新浏览器。新功能已通过离线测试及原生安装包检查，真实115、MoviePilot页面与Emby播放仍需部署验证。详情见 [当前状态](docs/STATUS.md)。

0.2.1修复旧页面缓存导致的打开即422。若仍看到“概览／分享／缓存”标签，请按Ctrl+F5刷新整个MoviePilot页面，重新打开插件；正确的新页面标题为“115 STRM 与 302”。

0.2.3生成时读取115完整目录祖先，直接选择剧名／类别目录或只填CID也带回上层类型和类别。例如 `/emby/电视剧/日韩剧/铁拳教育 (2026) {tmdbid=276161}/Season 01/第1集.mkv` 输出为 `/目标目录/电视剧/日韩剧/铁拳教育 (2026) {tmdbid=276161}/Season 01/第1集.mkv.strm`；`emby`这类类型前的库根前缀不带入。实际115目录身份或路径无法验证时停止本轮扫描，不猜测类别。旧位置STRM不自动删除，重新生成时播放token保持。
